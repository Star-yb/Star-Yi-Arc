# 补充文档

根目录 [README.md](../README.md) 是给仓库访客的总说明。这里放分主题的用法。

## 命名

| 规则 | 说明 |
|------|------|
| 文件名 | **kebab-case** 小写英文，例如 `admin-pages.md` |
| 配图 | 放在 `docs/assets/`，文件名同样 kebab-case，引用用相对路径 |
| 标题 | 文档内一级标题用中文主题名；代码、路径、类名用反引号 |

| 文件 | 内容 |
|------|------|
| [architecture.md](architecture.md) | 模块边界、请求分层、代码放在哪 |
| [admin-pages.md](admin-pages.md) | 给超级管理员后台加一个页面 |
| [crud.md](crud.md) | 用通用 CRUD 加一个资源 |
| [assets/](assets/) | 总览、Gradle 模块、请求鉴权配图 |
